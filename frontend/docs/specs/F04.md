# F04: Shell autenticado

- Fase: F04
- Data: 2026-11-16
- Depende de: F01 (cliente), F02 (componentes) e F03 (sessão)

## Objetivo

Entregar o shell autenticado com sidebar, header, conteúdo e rodapé discretos, navegação real, busca degradando com honestidade, atalhos de teclado, indicadores reais de alerta e responsividade de 360px a 1920px.

## Escopo

1. Route group `(app)` com layout único para todas as rotas privadas.
2. Sidebar com base petróleo, item ativo com indicador deslizante, modo trilho persistido, tooltips e logo que sempre leva a `/`.
3. Sidebar mobile em Sheet com um único botão de fechar, sem botão de fechar no desktop.
4. Sete itens na ordem pedida, com badge real de notificações não lidas.
5. Seletor de organização com dados reais quando existirem, mostrando sem dropdown quando houver uma só.
6. Rodapé da sidebar com cartão de ajuda por env e menu do usuário real.
7. Header com título da página, busca, idioma, tema e menu do usuário.
8. Paleta de comandos com Ctrl/Cmd+K, navegação e ações. Busca de documentos apenas se o backend oferecer.
9. Atalhos `g p`, `g v`, `n` e `?`.
10. PageTransition, breadcrumbs em rotas de detalhe, skeleton de sessão.
11. Título da aba e favicon refletindo alertas de risco alto pendentes.
12. Testes unitários e e2e de navegação.

## Decisões

- A API não expõe organização, avatar do Google nem busca. O shell mostra apenas o que a API devolve, registra as lacunas em `BACKEND_GAPS.md` e não inventa dados.
- O badge de notificações usa `GET /api/v1/notifications/unread-count`, que devolve o total real.
- O indicador de risco alto é derivado de notificações reais `high_risk_detected` não lidas, paginando o endpoint existente. Não há endpoint de contagem agregada.
- O modo trilho é uma preferência de interface persistida em cookie não sensível `sp_sidebar`.
- A busca de documentos não é chamada enquanto o endpoint não existir. A paleta mostra o estado de indisponibilidade e oferece navegação e ações.
- O avatar é composto pelas iniciais do nome real até a API devolver `avatar_url`.

## Critérios de aceite

- Sidebar sem controles duplicados em nenhum breakpoint.
- Logo sempre navega para `/`.
- Navegação pelos sete itens e pela conta.
- Colapso persistido e modo trilho com tooltips.
- Sheet mobile com exatamente um botão de fechar.
- Paleta abre com Ctrl/Cmd+K e navega.
- Atalhos `g p`, `g v`, `n` e `?` funcionam fora de campos editáveis.
- Título e favicon mudam com contagem real de alertas e voltam ao normal em zero.
- Sem rolagem horizontal em 360px.
- `npm run check` e `npm run test:e2e` verdes.
